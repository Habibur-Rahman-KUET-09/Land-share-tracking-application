# Cloud Functions অটো-ডিপ্লয় — একবারের সেটআপ

`functions/` (নোটিফিকেশন/রিমাইন্ডার) এখন থেকে GitHub Actions
(`.github/workflows/deploy-functions.yml`) দিয়ে **প্রতি push এ automatic
ডিপ্লয়** হবে — কোনো টার্মিনাল/CLI লাগবে না। কিন্তু এটা চালু করতে নিচের
দুটো ধাপ **একবার** করতে হবে (দুটোই ব্রাউজারে করা যায়, কোনো লোকাল ইনস্টল
লাগবে না)।

## ধাপ ১: একটা CI টোকেন বানান (Google Cloud Shell দিয়ে)

1. https://console.cloud.google.com এ যান, উপরে প্রজেক্ট ড্রপডাউন থেকে
   আপনার Firebase প্রজেক্টটা সিলেক্ট করুন।
2. উপরের ডান দিকে **Cloud Shell** আইকনে (`>_`) ক্লিক করুন — এটা ব্রাউজারেই
   একটা টার্মিনাল খুলবে, আগে থেকেই আপনার Google অ্যাকাউন্ট দিয়ে লগইন করা।
3. সেই টার্মিনালে লিখুন:
   ```bash
   npx firebase-tools login:ci
   ```
4. এটা একটা লিংক দেখাবে — ক্লিক করে অনুমোদন দিন, তারপর টার্মিনালে একটা
   লম্বা টোকেন প্রিন্ট হবে (`1//0g...` এরকম দেখতে)। পুরোটা কপি করে রাখুন —
   এটা একটা পাসওয়ার্ডের মতো, কারো সাথে শেয়ার করবেন না GitHub secret ছাড়া।

## ধাপ ২: GitHub এ দুটো secret যোগ করুন

1. এই রিপোর GitHub পেজে যান → **Settings** → বাম দিকে **Secrets and
   variables** → **Actions**।
2. **New repository secret** চাপুন, দুইবার:
   - নাম: `FIREBASE_TOKEN` — মান: ধাপ ১ থেকে পাওয়া টোকেন।
   - নাম: `FIREBASE_PROJECT_ID` — মান: আপনার Firebase প্রজেক্ট ID (Firebase
     Console → ⚙️ **Project settings** → **Project ID**, এটা প্রজেক্টের
     নামের মতো না-ও হতে পারে, আলাদা ID)।

ব্যস — এখন থেকে `functions/` ফোল্ডারে কোনো পরিবর্তন `main` ব্র্যাঞ্চে push
হলেই automatic ডিপ্লয় হয়ে যাবে। GitHub এর **Actions** ট্যাবে গিয়ে "Deploy
Functions" workflow-এর প্রোগ্রেস/লগ দেখতে পারবেন।

## মনে রাখবেন

- স্কেজুলড রিমাইন্ডার (`dailyReminders` — কিস্তির তারিখ কাছে আসছে/বাকি আছে)
  এর জন্য প্রজেক্ট **Blaze (pay-as-you-go)** প্ল্যানে থাকতে হবে। ফ্রি Spark
  প্ল্যানে থাকলে বাকি সব function (এন্ট্রি জমা/অনুমোদন/প্রত্যাখ্যান/বিল্ডার
  পেমেন্ট notification) ঠিকই ডিপ্লয় হবে, শুধু `dailyReminders` স্কিপ হয়ে
  যাবে — deploy ব্যর্থ হবে না, শুধু ওই একটা function-এর জন্য error লগ হবে।
- টোকেনের মেয়াদ ফুরালে (সাধারণত অনেক দিন থাকে) একই ধাপ ১ আবার করে
  `FIREBASE_TOKEN` secret আপডেট করলেই হবে।
