# Release answers — what to type in the Play Console

## Pricing and declarations (set once, some of them permanent)

| Field | Answer |
|---|---|
| Free or paid | **Free** |
| Contains ads | No |
| In-app purchases | No (nothing is configured yet; the badge appears by itself once subscription products exist) |
| Category | Finance |
| Financial features | "My app doesn't provide any financial features" |
| Target audience | 18+ |
| Account deletion URL | https://kistify.web.app/delete-account |
| Privacy policy URL | https://kistify.web.app/privacy |

**Free is a one-way door.** Play never lets a free app become paid; only
the reverse, once. That is the right choice anyway — the money is meant to
come from a per-group subscription, and a paid app would charge the nine
friends who are not paying for the group.

The financial-features answer is honest: the app records what a group has
collected. It moves no money, lends nothing, processes no payments and
touches no crypto. Answering otherwise invites a licensing review it would
not pass and does not need.

## Release notes (max 500 characters per language)

For a first release "what's new" really means "what this is", since
nobody has seen a previous version.
